# 프로젝트 관리 API 결정 기록

## D1. 프로젝트 목록 응답 형식

- 결정: `ListResponse<ProjectResponse>`로 전체 목록을 반환한다.
- 이유: 현재 목록 API의 주 사용처는 관리자 화면의 프로젝트 선택기이며, 한 번에 전체 선택지를 제공하는
  편이 단순하다. 공통 `ListResponse`도 재사용할 수 있다.
- 제외한 대안: 초기 버전부터 `PageResponse`를 사용하는 방안은 선택기에서 페이지를 합치는 추가 처리가
  필요해 현재 범위에 비해 복잡하다.

## D2. 프로젝트 목록 정렬 순서

- 결정: 프로젝트 이름 오름차순으로 반환한다.
- 이유: 프로젝트 선택기에서 항목 위치가 안정적이고 이름으로 찾기 쉽다.
- 제외한 대안: 최근 생성 순서는 새 프로젝트 노출에는 유리하지만 프로젝트 수가 늘어날수록 탐색성이
  떨어진다.
