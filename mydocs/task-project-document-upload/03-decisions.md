# 프로젝트 문서 업로드 결정 기록

## D1. 최초 지원 형식

- 결정: Markdown(.md), PDF(.pdf)만 허용한다.
- 근거: 사용자가 초기 지원 범위를 지정했다.

## D2. 원본 파일 보관과 중복 감지

- 결정: 정규화 Markdown과 메타데이터만 DB에 저장하고 원본 다운로드는 제공하지 않는다.
- 결정: 업로드한 원본 바이트의 SHA-256 해시를 저장해, 같은 프로젝트에 같은 파일을 다시 업로드하면 거절한다.
- 근거: 사용자 결정. 별도 파일 저장소 없이 중복 비용을 막는다.

## D3. PDF 텍스트 추출 정책

- 결정: Apache PDFBox로 텍스트를 추출하고, 빈 텍스트·추출 오류 PDF는 422로 거절한다.
- 근거: 사용자 결정. 검색 불가능한 빈 문서를 저장하지 않는다.
