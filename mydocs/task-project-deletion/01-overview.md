# 프로젝트 삭제 기능 Overview

## 목적

프로젝트 설정 화면에서 더 이상 사용하지 않는 프로젝트를 삭제할 수 있게 한다.
삭제 후에는 선택 상태와 목록을 안전하게 갱신해, 삭제한 프로젝트의 화면이나 데이터를 계속 참조하지 않게 한다.

## 현재 상태

- Spring API는 프로젝트 생성·수정과 연결 레포지토리 삭제만 제공한다.
- Admin 설정 화면은 프로젝트 기본 정보와 연결 레포지토리를 관리하지만 프로젝트 삭제 동작은 없다.
- Admin 앱은 서버 목록에서 사라진 선택 프로젝트 ID를 무효 처리하고 localStorage에서도 제거한다.

## 영향 범위

- 서버: `projects`는 Bugs, Issues, workflow runs, API keys, project sources, project contexts와 관계를 가진다.
- 에이전트: 문서·저장소 동기화와 PCM/저장소 스냅샷의 프로젝트별 데이터가 있을 수 있다.
- 화면: 삭제 버튼, 재확인 UX, 성공·실패 메시지, 삭제 뒤 선택 상태 및 캐시 갱신이 필요하다.

## 확인할 결정

프로젝트 삭제는 복구가 어려운 동작이다. 다음 단계에서 데이터 처리 방식, 재확인 방식, 에이전트 데이터 정리 범위와 실패 처리 기준을 결정한다.

## 범위 제외

프로젝트 보관(archive), 복구, 다중 프로젝트 일괄 삭제는 이번 요청에 포함하지 않는다.
